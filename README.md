# AI UI 自动化测试工具

通过大白话聊天操作浏览器，完成自动化UI测试。

## 功能特性

### 1. 项目管理
- 创建/编辑/删除测试项目
- 项目下管理测试用例和测试报告
- 项目仪表盘查看测试概况

### 2. 功能说明书管理
- 创建和编辑功能说明书（支持 Markdown）
- 版本管理
- 关联到具体项目

### 3. 测试数据管理
- 创建和管理测试数据集
- JSON 格式数据输入
- 数据集可关联到测试用例

### 4. AI 聊天驱动测试
- 内嵌浏览器视图
- 通过自然语言（大白话）描述操作
- AI 自动解析并执行浏览器操作
- 支持导航、点击、输入、验证等操作

### 5. 宏录制与回放
- 首次 AI 执行操作时自动录制为宏
- 操作出错后可录制修正操作
- 后续可直接播放宏，无需重复对话
- 宏管理：查看、编辑、删除

### 6. 测试报告
- 自动生成测试报告
- 展示通过率、失败详情、耗时统计
- 每个用例的步骤级别结果

## 技术栈

- **桌面端**: Electron（内嵌浏览器）
- **前端框架**: React + TypeScript
- **UI 组件**: Ant Design
- **状态管理**: Zustand
- **构建工具**: Vite

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建
npm run build
```

## 使用说明

1. **创建项目**：在"项目管理"页面创建测试项目，填入测试地址
2. **编写说明书**：在"功能说明书"页面编写功能描述
3. **准备数据**：在"测试数据"页面创建测试数据集
4. **执行测试**：在"AI测试执行"页面，选择项目后用自然语言描述测试步骤
5. **录制宏**：点击"录制宏"按钮，操作将被记录，下次可直接回放
6. **查看报告**：在"测试报告"页面查看测试结果
